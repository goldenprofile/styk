## Статус

Реализован первый Python-прототип: последовательный runtime, demo и Pi RPC backends, CLI и тонкое расширение Pi. Команды и фактические ограничения описаны в [корневом README](../README.md). Архитектурные документы задают целевую систему; наличие требования в спецификации не означает, что оно уже реализовано. Реальный Pi и расширение ещё требуют проверки в среде с Node.js/Pi.

Рабочая основа — спецификация v1.0 с дополнением Pi. При расхождениях исходное предложение рассматривается как исторический материал. Совместимость с продуктами проверялась по официальной документации 2026-11-13; перед реализацией необходимо закрепить версии SDK и проверить API на них.
